# Ecommerce-Sales-Tableau-Analysis

Interactive Tableau analysis of e-commerce sales, customer behavior, product performance, and operational metrics. The project demonstrates dashboard development, calculated fields, KPI analysis, filtering, and business-focused data visualization.

## Project Overview

This project uses Tableau to analyze e-commerce sales, customer performance, product performance, and operational metrics.

The dashboard provides interactive views of sales trends, regional performance, product performance, order status, delivery performance, and customer ratings.

## Tools Used

- Tableau Public
- Excel / CSV
- Data Visualization
- Business Analysis

## Key Analysis

- Sales performance by region
- Sales performance by category
- Monthly sales trends
- Top-performing products
- Customer sales performance
- Order cancellation and return rates
- Delivery performance
- Customer ratings
- Payment method analysis

## Files

- 'E-commerce Sales & Business Performance Analysis.twbx' – Tableau workbook
- 'Raw_Data.csv' – Dataset used for analysis

## Business Insights

- Electronics is the dominant sales category.
- Regional performance varies across revenue and profit.
- Cancellation and return rates provide opportunities for operational improvement.
- UPI is a major payment method among customers.
- Delivery time and customer ratings provide additional operational and customer-experience insights.
